# إدارة مزرعة الحمام (PWA)

تطبيق ويب تقدمي (PWA) محلي لإدارة مزرعة الحمام والسلاكات والأزواج والبيض والزغاليل والمبيعات والمخزون، يعمل بالكامل دون اتصال بالإنترنت عبر `IndexedDB`.

## التشغيل المحلي

```bash
bun install
bun run dev
```

## البناء للإنتاج

```bash
bun run build
```

يقوم أمر البناء تلقائياً بتوليد أيقونات PNG المطلوبة لنظامي Android و iOS من ملفات SVG عبر السكربت `scripts/generate-icons.mjs` ثم يبني حزمة الإنتاج في المجلد `dist/`.

## النشر على Vercel

1. ارفع المشروع إلى مستودع GitHub.
2. من لوحة تحكم Vercel اختر **Add New Project** واربط المستودع مباشرة.
3. سيتعرف Vercel تلقائياً على إعدادات **Vite** و **Bun** من ملف `bun.lock` (`bun run build` والمجلد `dist/`).
4. لا توجد أي مفاتيح سرية أو متغيرات بيئة مطلوبة، كما يضبط `vercel.json` ترويسات `sw.js` و `manifest.webmanifest` تلقائياً.
